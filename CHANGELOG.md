# Changelog

The changelog lives with the package it describes:
[`packages/engine/CHANGELOG.md`](packages/engine/CHANGELOG.md), written from
the changeset each pull request ships with. The same entries are published as
[GitHub releases](https://github.com/LiamRiddell/solve-engine/releases), one
per version, each carrying the verification section the release notes end
with.

This file used to hold the `1.0.0-beta.0` note and stopped there, which read
as though nothing had shipped since. That note is the first entry in the
package changelog.
